# Sources

TrueResolvers aggregates DNS resolvers from the following public projects. Each resolver is independently tested — upstream inclusion does not guarantee inclusion here.

| Source | Description | Link |
|--------|-------------|------|
| Trickest | Community-maintained resolver list with regular validation | [github.com/trickest/resolvers](https://github.com/trickest/resolvers) |
| public-dns.info | Global public DNS server directory | [public-dns.info](https://public-dns.info) |

These projects maintain their own validation pipelines. TrueResolvers uses them as raw input, applies independent testing and scoring, and publishes its own curated output.

Want to suggest an additional source? [Open an issue](https://github.com/0xAb1d/TrueResolvers/issues).
